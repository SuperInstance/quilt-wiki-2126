# 24: The Cell-Driven Control Loop

The Quilt robotics module 24 introduces a cell-driven control loop where a learned latent dynamics model actively contributes to the robot's control law. Unlike traditional feedback control systems where a dynamics model might serve as an observer, separate from the primary controller, this architecture integrates the cell's predictive capability directly into the torque generation mechanism. The primary objective is to enable a control system to adapt its reliance on a learned dynamics model based on the model's verified predictive accuracy, ensuring its contribution only when it accurately represents the system's behavior.

## Control Law Formulation

The control law for joint torque ($\tau$) is defined as a modification of a baseline proportional-derivative (PD) control, augmented by a cell-derived correction term:

$$ \tau = \tau_{pd} + \alpha \cdot (forecast_{1step} - q_{target}) \cdot K $$

Where:
*   `$\tau_{pd}$`: The baseline Proportional-Derivative (PD) control torque, calculated based on the target position (`$q_{target}$`), current position (`$q$`), and current velocity (`$\dot{q}$`). This provides a stable, non-adaptive control foundation.
*   `$forecast_{1step}$`: The 1-step-ahead position forecast generated by the integrated cell, conditioned on current and past robot states and control inputs.
*   `$q_{target}$`: The desired joint position at the next timestep.
*   `$K$`: A gain matrix or scalar, scaling the cell's corrective contribution.
*   `$\alpha$`: A scalar gating term, dynamically adjusting the influence of the cell's forecast. Its value is contingent on the cell's own predictive performance.

## Cell Operations in the Loop

The integration of the cell into the control loop involves five distinct operations, executed sequentially within each control tick:

1.  **State Initialization/Update**: The cell's internal state is initialized or updated using the current robot state (e.g., joint positions and velocities) and the control inputs (e.g., previously applied $\tau$). This provides the necessary context for the cell's predictions.
2.  **Forecast Computation**: The cell extrapolates its internal dynamics model to produce a 1-step-ahead forecast of the robot's state, specifically `$forecast_{1step}$` (joint position). This is a prediction of the robot's future position given current conditions.
3.  **Forecast Error Computation**: After the actual robot state (`$q_{actual}$`) becomes available at the end of the current timestep, the cell computes its internal 1-step-ahead forecast error (`$e_{forecast} = |forecast_{1step} - q_{actual}|$`). This error quantifies the discrepancy between the cell's prediction and the observed reality.
4.  **Parameter Update (Learning)**: Using the computed forecast error and an optimization algorithm (e.g., gradient descent), the cell's internal parameters (e.g., weights, biases, or latent state dynamics) are adjusted to minimize future forecast errors. This constitutes the cell's learning mechanism, enabling it to progressively refine its internal model of the robot's dynamics.
5.  **Output Emission**: The cell emits two primary outputs for the control loop:
    *   `$forecast_{1step}$`: Used directly in the control law for the predictive correction term.
    *   `$e_{forecast}$`: Used to compute the gating term `$\alpha$`, allowing the control system to weigh the cell's contribution based on its demonstrated accuracy.

## Alpha-Gating Mechanism

The scalar gating term $\alpha$ regulates the influence of the cell's forecast correction in the control law. This mechanism is critical for ensuring that the cell's contribution is applied only when its internal dynamics model has demonstrated sufficient predictive accuracy. $\alpha$ is computed as a sigmoid function of the cell's absolute forecast error:

$$ \alpha = \sigma(-C \cdot e_{forecast}) $$

Where:
*   `$e_{forecast}$`: The absolute 1-step-ahead forecast error computed by the cell.
*   `$C$`: A positive scaling constant that determines the sensitivity of the sigmoid function to the forecast error.

Initially, when the cell's dynamics model is unlearned, `$e_{forecast}$` will be high, resulting in an `$\alpha$` value close to 0. This effectively gates off the cell's corrective term, causing the control system to rely primarily on the baseline `$\tau_{pd}$`. As the cell learns the robot's dynamics and `$e_{forecast}$` decreases, `$\alpha$` approaches 1, allowing the cell's prediction-based correction to fully contribute to the control torque. This mechanism inherently enforces a requirement for the cell to learn and verify its understanding of the dynamics before its influence on the physical system is fully manifested.
